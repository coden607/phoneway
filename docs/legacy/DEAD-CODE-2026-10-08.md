# Legacy Dead-Code Removal — 2026-10-08 (Foundation Rebase v5)

## What was removed

14 JavaScript modules (~6,700 lines, ~59% of `js/`) plus one data file. Every one
was verified **unreferenced** from the live import graph rooted at `js/app.js`
(and from `index.html`, `api/`, and `data/`) before deletion. Cross-references
existed only *among the dead modules themselves* (e.g. `sensors.js` imported
`precisionEngine.js`; `ultraPrecision.js` imported `mlCalibration.js`,
`advancedFusion.js`, `environmentalSensors.js`).

## Why this is safe

The live path (`js/app.js` → `simpleScale.js`, `backgroundFusion.js`, `display.js`,
`referenceWeights.js`, `deviceCompat.js`, `telemetry.js`, `scaleMath.js`,
`sensorCombinations.js`, `liveUi.js`, `audio.js`, `cameraSensor.js`, `kalman.js`,
`data/error-logger.js`) never touched these files. The service worker
(`sw.js`) did **precache** them, which shipped ~6,700 dead lines to every
install — the sw.js asset list was updated in the same commit.

## What replaced their *intended* function (honestly)

| Dead module's promise | Live honest equivalent |
|---|---|
| mlCalibration ("NN") | `scaleMath.js` multi-point linear/quadratic curve fit |
| advancedVerification | `simpleScale.js` `verifyAgainstKnown` + `js/verificationLedger.js` |

| quantumFusion / sensors / advancedFusion | `simpleScale.js` gravity-plane delta + `backgroundFusion.js` confidence-only validators |
| learningEngine priors | `js/verificationLedger.js` — your own on-device verification record |
